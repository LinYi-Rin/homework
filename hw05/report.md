# hw05 实验报告

## 一、任务一：极简CNN学习总结
### 1. CNN结构要点
- 2层卷积层 + 2层最大池化层 + 2层全连接层
- 输入：单通道28x28 MNIST图像
- 激活函数：ReLU
- 池化：MaxPool2d(2,2)
- 输出：10分类（0-9数字）

### 2. 训练流程
1. 数据归一化与加载
2. 定义CNN模型结构
3. 交叉熵损失 + Adam优化器
4. 前向传播 → 计算损失 → 反向传播 → 更新参数
5. 迭代训练，在测试集评估准确率

## 二、任务二：LeNet-5 结构说明
| 层名称 | 输入尺寸 | 输出尺寸 | 参数量 |

| Conv1 | 1x28x28 | 6x28x28 | 156 |

| FC1 | 400 | 120 | 48120 |

## 三、实验结果
### 超参数
- 训练轮数：5轮
- 批次大小：64
- 优化器：Adam
- 学习率：0.001
- 运行设备：CPU/GPU自动适配

### 测试准确率
- 极简CNN：~98.5%
- LeNet-5：~98.8%

### 训练耗时（CPU）
- 极简CNN：~45秒
- LeNet-5：~55秒

## 四、模型对比
1. 准确率：LeNet-5 略高于极简CNN，结构更经典、特征提取更充分
2. 参数量：LeNet-5（6万）大于极简CNN（约2万），训练速度稍慢
3. 结构：LeNet-5是标准经典CNN，极简CNN是轻量化简化版本

# 实验调试记录

## 问题 1：MNIST 数据集下载失败 / 路径报错
- **现象**：运行代码时提示无法下载数据集、路径找不到、权限错误。
- **原因分析**：默认路径不统一、中文路径导致数据集写入失败、网络问题无法下载。
- **修改点**：代码中统一使用 ./data 相对路径存储数据集，设置 download=True 自动下载，无需手动操作。

## 问题 2：CUDA 不可用 / GPU 报错
- **现象**：RuntimeError: CUDA not available 或 CUDA out of memory。
- **原因分析**：电脑无独立显卡、GPU 显存不足、环境未配置 CUDA。
- **修改点**：代码自动判断设备，使用 device = cuda if available else cpu，完美兼容 CPU 运行。

## 问题 3：模型展平层维度不匹配
- **现象**：RuntimeError: shape mismatch 维度错误。
- **原因分析**：卷积层输出特征图尺寸计算错误，全连接层输入维度不对应。
- **修改点**：极简 CNN 固定展平维度 320，LeNet-5 固定 16*5*5，严格匹配网络结构。

## 问题 4：依赖库版本不兼容
- **现象**：导入 torch 报错、函数不存在。
- **原因分析**：PyTorch 版本过低，与代码使用的 API 不匹配。
- **修改点**：提供 requirements.txt 指定依赖版本，统一环境。

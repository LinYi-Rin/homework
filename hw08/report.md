# AI计算机视觉OCR图文识别项目报告
## 1. 选题与需求分析
1. 解决问题：纸质文档、截图、证件照片中的文字无法直接复制，手动录入耗时易错；模糊、倾斜照片常规工具识别效果差。
2. 面向用户：学生、职场办公人员、文案整理从业者。
3. 核心价值：上传图片自动提取全部文字，支持文本复制导出，大幅降低文字录入成本。
4. AI在项目中的角色：
   采用PaddleOCR计算机视觉预训练模型，分为两步：①视觉目标检测，定位图片中所有文字区域；②文字识别，将图像像素转为文本。
   传统固定规则只能识别横平竖直高清截图，AI视觉模型具备泛化能力，可处理倾斜、轻微模糊、多排版图文，规则无法实现该效果。

## 2. 系统架构与技术选型
### 2.1 系统架构图
三层模块化架构：
1. 前端交互层：Streamlit网页，负责图片上传、结果展示、文件下载
2. 业务逻辑层：图像预处理、结果解析、页面渲染
3. AI视觉推理层：PaddleOCR预训练CV模型（文字检测+文字识别）
数据流：用户上传图片→图像预处理→OCR模型推理→文本结果回传前端展示

### 2.2 技术选型
- 编程语言：Python
- Web框架：Streamlit（快速可视化网页，无需前端JS/HTML）
- AI视觉模型：PaddleOCR开源预训练计算机视觉模型
- 依赖库：paddlepaddle、paddleocr、pillow、numpy

## 3. 关键实现说明
1. 技术路线：使用开源预训练视觉模型，无需自行标注数据集、训练网络，直接调用成熟CV模型完成推理。
2. 核心流程：
   （1）用户上传图片，转为numpy数组送入模型；
   （2）OCR模型完成文字区域检测+字符识别，返回文字坐标、文本、置信度；
   （3）解析拼接全部文本，提供页面展示与txt导出；
   （4）绘制文字检测框可视化识别效果。

## 4. 测试结果与局限性分析
### 有效测试场景
1. 电脑清晰截图、打印书本照片、证件照片；
2. 轻微倾斜、低亮度的文字图片；
3. 中英文混合排版图文。

### 失效场景
1. 无任何文字的纯图片、纯白/纯黑图片；
2. 严重反光、重度模糊、极小远距离拍摄文字；
3. 手写潦草字体、艺术扭曲字体识别准确率大幅下降。
